# 🌱 植物分類クエスト

中学1年理科「植物の分類・花のつくり」を復習するための、GitHub Pages向けの静的クイズアプリです。

## 実装内容

- 総合テスト：12問
- 花のつくり：8問
- 分類マスター：8問
- 単子葉類 vs 双子葉類：8問
- 各モードで問題をランダムにシャッフル
- 選択直後に正誤と解説を表示
- 最後に100点換算の得点、正答数、正答率を表示
- 間違えた問題だけ復習表示
- ブラウザのlocalStorageに最高得点を保存
- PC・タブレット・スマートフォン向けレスポンシブ対応
- 外部ライブラリ不要、HTML/CSS/JavaScriptのみ

## ファイル

- `index.html`：画面構成
- `style.css`：デザイン
- `script.js`：問題データとクイズ処理
- `fix.js`：表示上の軽微な補正

## GitHub Pages

GitHubのリポジトリ設定から Pages を有効化し、`main` ブランチのルートを公開対象にすると、そのままWebサイトとして公開できます。
